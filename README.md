# NEXT TURN: Bab Baru Bareng — purwarupa digital

Situs purwarupa board game NEXT TURN (RE:PLAY, Kelompok Cecep KSD, SMAS 1 BPK Penabur Bandung).

- index.html: model 3D, isi kotak, 60 kartu, buku aturan
- qr.html: membuat QR menuju situs ini
- *.pdf: file print & play ukuran asli

Cara pasang: unggah semua file ke repositori, lalu Settings > Pages > Deploy from a branch > main > / (root) > Save.
